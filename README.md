## 👋 About me

I design, build and deliver **Odoo ERP** solutions that companies run every day. Since January 2024 I have delivered **19 Odoo projects, all live in production**, for companies in manufacturing, distribution, retail and services. I handle a project from the first client meeting to go-live and support: analysis, specifications, solution design, development, deployment and user training. Based in Tunisia, open to relocation.

## 🏗️ How I deliver a project, end to end

- 📝 **Functional specifications**: client workshops, workflows, mock-ups, open questions
- 🧠 **Solution design**: reuse standard Odoo first, extend by inheritance, keep upgrades easy
- 🗂️ **Technical specifications and sprint planning**: module map, tasks, estimates, test plans
- 💻 **Development**: Python, ORM, XML/QWeb, OWL, REST/JSON APIs, reports
- 🧪 **Testing and validation**: test databases, functional checks, client acceptance
- 🚀 **Deployment**: Ubuntu, Docker (Odoo, PostgreSQL, Nginx), Git, controlled releases
- 🎓 **Training and support**: user training, go-live support; Odoo trainer at ISET Zaghouan
